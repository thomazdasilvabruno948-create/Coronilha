# Coronilha Pro

Crie um site completo, moderno, responsivo e profissional para uma imobiliária brasileira chamada Coronilha Imobiliária.

O objetivo é criar uma experiência visual marcante, elegante e moderna, mas também extremamente prática para navegação em celulares. O site deve ser pensado desde o início para funcionar muito bem em dispositivos móveis, pois futuramente páginas individuais de imóveis poderão ser acessadas por QR Codes presentes em placas físicas de venda e aluguel.

1. IDENTIDADE VISUAL

Utilize como referência visual a identidade da logo da Coronilha Imobiliária, baseada principalmente em:

vermelho;

branco;

cinza.

O vermelho deve ser utilizado como cor de destaque e interação, e não como cor predominante em toda a página.

O visual deve combinar:

estética moderna de imobiliária;

aparência profissional;

fotografias grandes e valorizadas;

bastante espaço visual;

elementos geométricos sutis;

algumas diagonais e cortes angulares inspirados nas formas geométricas presentes na logo.

Não transformar o site em um design excessivamente chamativo. As formas geométricas devem funcionar como uma assinatura visual da marca.

Evite aparência de template genérico de imobiliária.

A tipografia deve ser moderna, elegante e extremamente legível.

2. EXPERIÊNCIA DE ENTRADA

Ao acessar o site pela primeira vez, apresentar uma tela inicial minimalista contendo a logo da Coronilha Imobiliária centralizada.

A logo deve aparecer de forma elegante e, depois de um curto período, desaparecer utilizando uma animação suave de fade-out.

Após o fade-out, a página principal deve surgir com uma transição suave.

A animação deve ser rápida o suficiente para não prejudicar a experiência do usuário.

3. BARRA DE NAVEGAÇÃO

No topo da página inicial, criar uma barra de navegação limpa e elegante contendo:

CONTATO

ENDEREÇO

INSTAGRAM

SOBRE NÓS

Os elementos devem funcionar como botões/links.

No desktop, utilizar uma navegação horizontal.

No celular, adaptar a navegação para uma interface adequada a telas pequenas, utilizando um menu compacto caso necessário.

Os links devem utilizar animações sutis de hover/interação.

4. HERO

Criar uma seção hero visualmente impactante.

A logo da Coronilha Imobiliária deve aparecer novamente nessa seção.

Abaixo da logo, criar um grande carrossel horizontal de imóveis em destaque.

O carrossel deve ser um elemento visual importante da página.

Utilizar imagens em proporção 16:9, preferencialmente grandes e de alta qualidade.

O carrossel deve:

exibir um imóvel em destaque;

permitir navegação para o imóvel anterior e próximo;

mover os imóveis horizontalmente da direita para a esquerda;

possuir transições suaves;

permitir navegação por setas no desktop;

permitir arrastar/swipe no celular;

possuir indicadores de posição;

permitir clicar/tocar na imagem para abrir a página específica daquele imóvel.

O comportamento deve ser semelhante ao de carrosséis modernos de aplicativos e sites.

No celular, o usuário deve conseguir segurar e arrastar a imagem para visualizar os outros imóveis.

Não utilizar um carrossel automático excessivamente rápido.

5. INFORMAÇÕES SOBRE O IMÓVEL NO CARROSSEL

Cada item do carrossel deve possuir uma estrutura de dados própria.

Cada imóvel deverá poder possuir:

título;

categoria;

preço;

localização;

imagem principal;

identificador único;

URL/página individual.

As informações devem ser estruturadas de maneira que possam posteriormente ser substituídas ou atualizadas sem precisar reconstruir manualmente o layout inteiro.

Não espalhar informações dos imóveis diretamente em vários componentes da interface.

Criar uma estrutura preparada para que os imóveis sejam tratados como dados independentes.

6. CATEGORIAS

Abaixo do carrossel, criar uma seção com três grandes opções:

IMÓVEIS

TERRENOS

LOTEAMENTOS

Cada opção deve funcionar como uma entrada visual para sua respectiva categoria.

Utilizar imagens ou elementos visuais grandes.

Ao passar o mouse no desktop ou tocar no celular, criar uma interação visual elegante.

A interação pode utilizar o vermelho da identidade visual.

7. CARDÁPIO PRINCIPAL

Criar uma seção visual de navegação que funcione como um "cardápio" do site.

Essa seção deve apresentar de maneira clara e visual as principais áreas:

Imóveis

Terrenos

Loteamentos

Sobre nós

Endereço

Contato

Não criar simplesmente uma lista de links.

Criar uma composição visual moderna utilizando cards, imagens, formas geométricas e espaços bem definidos.

A seção deve manter a identidade visual da Coronilha.

8. CATÁLOGO DE IMÓVEIS

Ao clicar em "Imóveis", abrir uma página de catálogo.

O catálogo deve utilizar a abordagem visual de um grid de cards grandes, combinando organização com forte presença fotográfica.

Cada card deve apresentar:

foto principal grande;

título;

localização;

preço;

informações resumidas;

botão "VER IMÓVEL".

Os cards devem possuir animações sutis de interação.

Criar filtros para facilitar a busca, incluindo inicialmente:

tipo de imóvel;

localização;

faixa de preço;

quantidade de quartos;

área.

O sistema deve ser responsivo.

No celular, os cards devem ser reorganizados para uma coluna ou layout adequado à largura da tela.

9. TERRENOS

Criar uma página semelhante para terrenos.

Os terrenos devem possuir estrutura própria, podendo conter:

título;

localização;

preço;

área;

descrição;

fotos;

vídeo;

mapa;

informações adicionais.

10. LOTEAMENTOS

Criar uma página específica para loteamentos.

Cada loteamento deve poder apresentar:

nome;

localização;

imagens;

descrição;

mapa;

informações sobre os lotes;

características do empreendimento;

contato.

A estrutura deve permitir expansão futura.

11. PÁGINA INDIVIDUAL DO IMÓVEL

Ao clicar em um imóvel no carrossel ou no catálogo, abrir uma página específica daquele imóvel.

A página deve apresentar:

título;

categoria;

localização;

preço;

foto principal;

galeria de fotos;

vídeo, quando disponível;

área;

quartos;

banheiros;

vagas;

descrição;

mapa/localização;

botão de contato.

Criar uma apresentação visual elegante e focada nas fotografias.

A página deve possuir um botão de destaque:

TENHO INTERESSE

Esse botão deverá futuramente poder abrir o WhatsApp da imobiliária com uma mensagem pré-preenchida identificando automaticamente o imóvel.

Exemplo:

"Olá! Tenho interesse no imóvel [NOME DO IMÓVEL]."

12. QR CODES

A arquitetura do site deve ser preparada para que cada imóvel possua uma URL própria e estável.

Exemplo:

/imovel/casa-centro

ou

/imovel/identificador-do-imovel

O objetivo é permitir futuramente a criação de QR Codes individuais para placas físicas.

Quando uma pessoa escanear o QR Code de uma placa, ela deverá ser levada diretamente para a página daquele imóvel.

13. CONTATO

No final da página inicial, criar uma seção de contato elegante e simples.

Incluir espaços para:

WhatsApp;

telefone;

Instagram;

e-mail;

endereço.

Os contatos devem ser apresentados como botões ou elementos interativos.

No celular, os botões devem ser fáceis de tocar.

14. SOBRE NÓS

Criar uma seção/página "Sobre nós" preparada para receber posteriormente:

história da empresa;

informações da imobiliária;

equipe;

valores;

missão;

diferenciais.

Por enquanto, utilizar conteúdo fictício claramente estruturado como conteúdo temporário, sem utilizar Lorem Ipsum.

15. ADMINISTRAÇÃO FUTURA

A arquitetura do projeto deve ser preparada desde o início para uma futura área administrativa protegida por login.

Essa área deverá futuramente permitir:

adicionar imóvel;

editar imóvel;

excluir imóvel;

alterar fotos;

alterar preço;

alterar descrição;

alterar localização;

alterar características;

definir imóvel como destaque;

retirar imóvel dos destaques.

O conceito de "Imóvel em destaque" deve ser preparado para que, no futuro, marcar um imóvel como destaque faça com que ele possa aparecer automaticamente no carrossel da página inicial.

IMPORTANTE:

Não criar informações de imóveis espalhadas diretamente pelo código.

Estruturar os dados de forma organizada e reutilizável para que posteriormente seja possível conectar um banco de dados e um painel administrativo sem precisar reconstruir toda a interface.

16. RESPONSIVIDADE

O site deve ser desenvolvido pensando em desktop e celular desde o início.

Priorizar especialmente a experiência mobile.

O site deverá funcionar corretamente em:

celulares;

tablets;

notebooks;

monitores grandes.

No celular:

navegação simplificada;

carrossel com swipe;

botões grandes o suficiente para toque;

imagens bem dimensionadas;

textos legíveis;

carregamento visual organizado.

17. ANIMAÇÕES

Utilizar animações modernas e discretas:

fade-in;

fade-out;

transições suaves;

animações de entrada durante a rolagem;

hover nos botões;

transições do carrossel;

feedback visual ao tocar nos elementos.

Evitar animações excessivas.

A sensação geral deve ser de um site profissional e premium.

18. FOTOGRAFIAS

Utilizar imagens de imóveis realistas e de alta qualidade como conteúdo demonstrativo.

As imagens devem funcionar como placeholders facilmente substituíveis posteriormente.

Não utilizar imagens aleatórias que não tenham relação com o conteúdo.

19. EXPERIÊNCIA GERAL

O site deve transmitir:

confiança;

profissionalismo;

modernidade;

qualidade;

facilidade de navegação;

proximidade.

O visitante deve conseguir chegar a um imóvel em poucos cliques.

O design deve valorizar os imóveis e não competir com eles.

20. IMPORTANTE — PRIMEIRA VERSÃO

Esta primeira versão deve priorizar:

estrutura visual completa;

navegação;

carrossel funcional;

catálogo;

páginas individuais;

responsividade;

identidade visual;

arquitetura organizada dos dados.

Utilize imóveis fictícios como conteúdo inicial.

Não implementar ainda um painel administrativo complexo se isso exigir infraestrutura adicional. Entretanto, deixe a arquitetura preparada para sua implementação futura.

Não substituir o conceito acima por um template genérico de imobiliária.

Não remover funcionalidades simplesmente para simplificar o projeto.

O resultado deve parecer um site real e profissional da Coronilha Imobiliária, e não uma demonstração genérica de IA.

Todo o conteúdo visível deve estar em português do Brasil.
